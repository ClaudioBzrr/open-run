GPS without the noise

A stationary phone
should look stationary.

GPS drift is normal. Turning that drift into fake distance is not. Open Run filters location fixes before they reach the track.

Read the filter ↗
01

Doppler speed

Near-zero speed keeps the position anchor fixed instead of accepting multipath jumps as real movement.

02

Accuracy-scaled deadband

The movement threshold grows with reported GPS accuracy, so a 20 m fix cannot create a 2 m segment.

03

Multi-fix confirmation

When speed is ambiguous, three consistent fixes are required before a new segment is committed.

04

Barometer-assisted elevation

Pressure altitude is calibrated from the first valid GPS altitude and preferred over noisy GPS elevation.

Privacy by architecture

No account.
No analytics.
No cloud sync.

Your activity database is private to the app. Open Run does not create a profile, upload your track or require a login.

  • Activity storage: app-private Room database
  • Location data: never uploaded by the app
  • Maps: OpenStreetMap tiles downloaded when online
  • Backups: encrypted locally, passphrase never stored
  • Exports: created only when you choose them

Map tiles reveal the area you view to the tile provider, as with any online map. The recorded track is not uploaded as a file.

Questions, answered

Open Run FAQ

The short answers for runners, walkers and anyone evaluating the app.

Is Open Run free?

Yes. There is no account, subscription or advertising SDK. Download the signed APK directly from GitHub Releases.

Does it work offline?

Recording, history, splits, backups and exports work offline. Map tiles and the share-card map background need an internet connection; without them, the route is drawn on a clean background.

Where is my data stored?

Sessions, points, pauses and splits are stored in an app-private Room database on the device. Open Run has no cloud sync. GPX, FIT, PDF, XLSX and .runbackup files are created only when you export them.

Can I import activities into Garmin, Strava or Komoot?

Open Run exports standard GPX 1.1 and Garmin FIT files. Any service that supports those formats can import them.

Is it on the Play Store?

Not yet. Releases are distributed as signed APKs on GitHub. Android may ask you to allow installation from your browser or file manager the first time.

Which Android versions are supported?

Android 8.0 (API 26) or newer. Google Play Services is required for high-accuracy fused location; maps use OpenStreetMap tiles and do not need a Google Maps API key.

Does it support pauses and auto-pause?

Manual pause and resume are supported and pauses are persisted exactly. Automatic pause exists in the tracking engine but is disabled by default in this release.

What happens if the app is closed mid-run?

The unfinished session remains in the local database. Reopening the app offers Resume, Finish and save, or Discard. Resume restores points, pauses, distance and splits.
